# Intelligent Campus Portal 🏫🔍

An AI-driven, web-based lost and found system developed for university campuses. This system replaces traditional manual data entry with Computer Vision and fuzzy-logic matching algorithms to efficiently reunite students with their lost property.

## 💻 Tech Stack
* **Frontend:** React.js / HTML5, Tailwind CSS
* **Backend:** Python, FastAPI
* **Database:** Firebase / SQLite
* **Artificial Intelligence:** HuggingFace Vision AI (Image Classification), Levenshtein Distance (NLP)
* **Location Services:** HTML5 Geolocation API

## 🚀 Key Features
* **AI Image Tagging:** Automatically classifies found items to bypass manual data entry.
* **Smart Matching:** Fuzzy-logic search connects missing item reports with database inventory.
* **Spatial Tracking:** Pinpoint exact item recovery locations on a campus map.
* **Admin Dashboard:** Secure verification and resolution of active claims.
